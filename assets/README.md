# Otty brand assets

Primary colour: `#10B981`.

The SVG files use editable vector paths and gradients, with no embedded raster images. PNG counterparts are rendered directly from those SVG files at 1200 x 1200 pixels.

- `otty-light`: white background, green swirls.
- `otty-dark`: near-black `#15181C` background, green swirls.
- `otty-green`: Emerald background, white swirls.
- `otty-transparent`: transparent background, green swirls.

The vector redraw was approved on 22 November 2026. Otty is the OTPanda mascot. These files do not choose a software or artwork license.
