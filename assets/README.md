# Otty brand assets

Primary colour: `#10B981`.

The SVG files use editable vector paths and gradients, with no embedded raster images. PNG counterparts are rendered directly from those SVG files at 1200 x 1200 pixels.

- `otty-light`: white background, green swirls.
- `otty-dark`: near-black `#15181C` background, green swirls.
- `otty-green`: Emerald background, white swirls.
- `otty-transparent`: transparent background, green swirls.

The vector redraw was approved on 22 November 2026. Otty is the OTPanda mascot. These files do not choose a software or artwork license.

## Brand mark (`assets/brand`)

The V7 OTPanda brand mark is the centered panda with a plain inward asterisk disc, on a green container. It has no swirl or paw fingers. Use `otty-tile-v7.svg` for the rounded tile and `otty-circle-v7.svg` for a circle. The `-small-v7` assets use the same geometry for 16 to 48 px. The landing page uses `apple-touch-icon-v7.png` and `social-card-v7.png`.

The large Otty illustration (`otty-*` files above) is the character artwork. It stays in the landing page hero and is not the brand mark.
